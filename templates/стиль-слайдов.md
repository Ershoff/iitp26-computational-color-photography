# Стиль слайдов IITP'26

Опора: [`Презентации/Lec_1,2_intro2color.pptx`](../Презентации/Lec_1,2_intro2color.pptx) — **как реально читались Л1 и Л2** (Google Slides, тема **Simple Light**, 49 слайдов, 10″×5.625″). Не `Lec_2_linear_model.pptx` и не исчезнувший `Lec_1_intro2color.pptx`.

Сборщик-образец: [`weeks/03/build_lec3.py`](../weeks/03/build_lec3.py). Скил: [`.cursor/skills/iitp-slides/SKILL.md`](../.cursor/skills/iitp-slides/SKILL.md). Тамбнейлы XML — личный `~/.cursor/skills/pptx`; в репозиторий его не класть.

---

## Жёсткие запреты

- Не собирать дек «с нуля» в 13.333″×7.5″, Calibri, синяя шапка, цветной фон.
- Не менять тему, размер слайда, основные поля.
- Не писать на слайде программу курса и веса оценки.
- Не ставить титул ТМШ / AIRI / МФТИ / ИТМО. Номер пары — IITP'26, лекция N.
- Не копировать слайд в слайд: одна мысль, картинка или формула держит слайд.
- Не мельчить шрифт, чтобы впихнуть абзац.

## Как клонировать шаблон

1. Открыть `Lec_1,2_intro2color.pptx` через `Presentation(...)`.
2. Удалить все слайды, **мастера и тему оставить**.
3. Наполнять штатными макетами. Текст — **в плейсхолдер тела**, не только `add_textbox`.
4. Картинки — готовые (из этого же дека, статьи, Commons), подпись источника 11 pt внизу.

**Ловушка мастеров.** В файле три мастера. `prs.slide_layouts` и первое `TITLE_ONLY` — пустой Simple Light **без линеек**. Живые слайды (47 из 49) сидят на **третьем** мастере, `slideLayout23`: `TITLE_ONLY` плюс две горизонтальные линии (`cxnSp`, `dk2`). Верхняя: 0.355″ / 0.455″, 3 pt; нижняя: ~0.41″ / 5.184″, 1.5 pt. Титул Л1 — `BLANK` (`slideLayout12`), без линеек. Сборщик берёт `TITLE_ONLY` с `cxnSp`.

На `slideLayout23` три плейсхолдера:

| idx | type | положение |
|---|---|---|
| title | title | 0.355, 0.463, 9.183×0.695 |
| 1 | body | 0.912, 1.236, 8.112×3.549 |
| 12 | sldNum | 9.294, 5.128, 0.600×0.430 |

Размер: **10″ × 5.625″**, EMU `9144000 × 5143500`.

---

## Макеты

| Макет | Когда |
|---|---|
| `TITLE` (первый мастер) | Титул IITP-лекции. В файле Л1+Л2 титул на `BLANK` с логотипами ТМШ — **не копировать**. |
| `TITLE_ONLY` третьего мастера | Почти все слайды. Заголовок + тело (плейсхолдер) + картинка. Перебивки — тот же макет, пустой title, 30 pt в body. |
| `TITLE_AND_BODY` / `SECTION_HEADER` | В живом деке не используются. У них нет линеек. |
| `BLANK` третьего мастера (`slideLayout24`) | Финальный «спасибо», если нужен. |
| `TITLE_AND_TWO_COLUMNS` с линейками | Есть на третьем мастере, в Л1 почти не брали. |

Номер слайда — плейсхолдер снизу справа, не трогать.

## Как наполняют живые слайды Л1+Л2

Не конспект. Картинка держит слайд, текста мало.

1. **Только текст.** Заголовок + 1–4 коротких абзаца в *body-плейсхолдере*. Так «Что из этого следует?», закрытие.
2. **Текст слева, фигура справа** (самый частый для «идея + пример»). Body сужают до ~4.68″. Картинка **5.273″, 1.269″, ~4.38×3.31″** («Что думают биологи?», ЗСЧ).
3. **Одна большая фигура** под заголовком, поля ~0.2–0.5″, подпись 11 pt на нижней линейке («Изображения с разных камер», спектры ламп).
4. **Две фигуры в ряд** — колориметрия, локус, Планк: левая шире (~4.8–5.3″), правая уже (~3.1–3.3″). Подписи мелкие над/под, не три колонки фото.
5. **Вопрос.** Пустой title. Одна строка 30 pt жирным по центру в body, top **2.153″** (иногда 1.736″). «Вопрос N: …»
6. **Подпись источника** — отдельный textbox top **5.188″**, 11 pt, серый; не наезжать на номер слайда.

Редко: три равные фото-колонки. Не делать это основным приёмом. Коллаж в Л1 — нахлёст картинок, не сетка 1/3.

Формулу, схему, локус, CMF, Планк, глаз, метамеры салата — **брать из `Lec_1,2`**, не рисовать заново серые прямоугольники matplotlib. Новые графики (пересечения, ступеньки) — в том же языке: тонкие оси, чёрные кривые, белый фон.

## Геометрия (дюймы, с живых слайдов)

- Заголовок: **0.355 / 0.463 / 9.183 / 0.695**.
- Тело (полный): **0.912 / 1.236 / 8.112 / 3.549**.
- Тело при картинке справа: ширина **4.677–4.95″**.
- Картинка справа: **5.273 / 1.269 / 4.375 / 3.306**.
- Вопрос: **0.912 / 2.153 / 8.112 / 1.481**.
- Подпись: **0.447 / 5.188 / 9.1 / 0.387**.

Не сдвигать заголовок «для красоты». Номер слайда не перекрывать.

## Шрифт и цвет

Simple Light, чёрное на белом.

- **Lato**. Не Calibri. `text_frame.text =` схлопывает прогоны — писать в `run.text` и `font.name = "Lato"`.
- Цвета: чёрный `#000000`, белый `#FFFFFF`, серый `#595959`, бледный `#EEEEEE`, акцент `#4285F4`.
- Синий — пауза / ссылка, не заливка.
- Заголовок **28 pt** жирный (мастер). Тело **18 pt**. Подпись **11 pt**. Вопрос **30 pt**. Титул курса **36 pt**. Пауза: курсив 14 pt `#4285F4`.

## Ритм пары

Как Л1+Л2: вопрос → картинка → две–четыре строки → следующий вопрос.

На слайде 3–5 коротких строк, не абзац. Таблица — только сравнение двух столбцов. Имена — по делу.

В `slides.md` можно держать «Пауза» и «Не на этот слайд». На дек — только то, что видно студенту.

## Быстрая проверка

- Клон именно `Lec_1,2_intro2color.pptx`.
- 10×5.625, не 13.3×7.5.
- Контент → `slideLayout23`, не `slideLayout5`.
- Линейки колонтитулов видны.
- Текст в body-плейсхолдере, Lato, 18 pt.
- Картинки готовые, не серые блоки «источник / СДФОС / сенсор».
- Источник 11 pt, номер слайда на месте.
- Нет логотипов ТМШ на титуле IITP.
