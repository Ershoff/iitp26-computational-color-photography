# Рассылка материалов до занятия

Копировать в почту / чат курса **не позже чем за N дней** до пары (по умолчанию: за 5 дней; к первой лекции — вместе с программой).

Не превращать рассылку в домашку: никаких «сдайте код / конспект / эссе». Просьба одна — **принести вопросы**.

---

**Тема:** IITP'26, лекция N. «…название…»

Текст:

```
Коллеги,

к следующей лекции (дата, пара) материалы ниже.
Просьба до занятия прислать вопросы — это основная активность курса, не код.

Как писать вопросы: файл templates/вопросы-студентов.md
Куда: …ссылка на таблицу / тред / форму…
До: …дедлайн, например вечер накануне…

Что читать / смотреть обязательно (коротко):
1. …
2. …

Что можно пролистать:
- …

На лекции будет повествование и разбор ваших вопросов.
[Если тест:] На этой паре короткий тест по уже пройденному (лекции …).

Программа курса: ПРОГРАММА.md
Brief лекции (для преподавателя, студентам по желанию): weeks/NN/brief.md
```

---

## Чеклист преподавателя перед рассылкой

- Подставить номер, дату, название из [weeks/](../weeks/).
- Приложить или дать путь к слайдам / PDF / статье. Не присылать «весь прошлый курс».
- Отметить, будет ли тест (Л3, Л6, Л9, Л12).
- Напомнить, что вопросы можно слабые и уточняющие: «не понял, зачем конус» — нормальный вопрос.
- Не просить уникальности «чтобы ИИ не написал». Если вопрос дельный — его разбираем, чей бы ни был черновик.
