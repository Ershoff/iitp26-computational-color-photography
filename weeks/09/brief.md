# Л9. Коррекция освещения

**Блок Б.** **Тест** по Л7–Л9 (дебайер, оценка, коррекция).

## Зачем эта пара

Перекрасить снимок под целевой свет. Поканальный gain и спектральные модели (зональная, Гаусс, фон Мизес). Это репродукция, не повтор оценки.

## Пре-материалы

Обязательно:

- часть `Lec_4.CST+AWB.pptx` / illumination compensation из прошлых лет;
- три спектральные модели — по слайду или по конспекту: идея и 2–3 свойства каждой.

По желанию:

- von Kries / диагональная адаптация — связь с Л4а и отличие: наблюдатель vs. камера.

## Куда целиться вопросам

- Чем коррекция отличается от оценки: другая некорректность.
- Когда трёх диагональных коэффициентов мало.
- Зачем спектральная модель, если уже есть три RGB.
- Свойства «хорошей» модели спектра света.
- Зональная / Гаусс / фон Мизес: носитель, гладкость, поведение на краях видимого.

## Повествование

1. Цель: изображение «как при другом свете» или «как у наблюдателя при D65» — проговорить целевую.
2. Поканальный gain: быстро, ломается на метамерах поверхностей.
3. Спектральный подход.
4. Три модели.
5. Датасеты и метрики vs. оценка (Л8).

Тест — короткий, уже пройденное Б4–Б6.
