Источник старого дека: [Презентации/Lec_1_intro2color.pptx](../../Презентации/Lec_1_intro2color.pptx) (49 слайдов, титул ТМШ).

## Старый дек S1–S49 → куда (после факта Л1)

Прочитано примерно S1–S17 (титул ТМШ, мотивация, кусок камеры, «что такое цвет», начало «как измеряют»).

| Старый | Содержание | Куда дальше |
|---|---|---|
| S1–S3 | ТМШ, план обзора, мотивация ИИ | не повторять как титул |
| S4–S8 | Камера, меню, ISO, Brown | Л2 (приёмники-камеры) точечно; подробно Л4б/Л5 |
| S9 | RGB — не цвет | при необходимости повтор на Л2, слайд «зачем линейная модель» |
| S10–S16 | Ощущение, кора, иллюзия, спектр как поток | Л1 уже было; 1 слайд-повтор на Л2 ок |
| S17–S21 | Как измеряют; Юнг–Максвелл | **Л2** |
| S22 | Координаты без XYZ | **Л2** (связь пространств) |
| S23–S27 | V(λ), CIE RGB/XYZ, диаграмма | Л3 |
| S28–S38 | CAM, Lab, Нюберг, адаптация | следующие пары блока А (свойства зрительной системы / Л4а) |
| S39 | colour-science | реквизит после демо |
| S43–S45 | Планк, осветители | Л3 |
| S41–S42, S46 | sRGB, белая точка | Л10 |
| S49 | Контакты | любые титулы |

Раутиан и пороги — не на Л2: следующие лекции блока А про свойства зрительной системы.
